📧 mail-monitor

Postfix / Dovecot 로그를 실시간으로 보여주는 터미널(TUI) 대시보드. Go + Bubble Tea

설치

curl -fsSL https://LeeAn0121.github.io/mail-monitor/install.sh | bash

Ubuntu/Debian용 .deb 패키지를 GitHub Releases에서 받아 dpkg -i로 설치합니다.

실행

mail-monitor

/var/log/mail.log 읽기 권한이 필요합니다. sudo 비밀번호 없이 실행하려면:

echo "$USER ALL=(ALL) NOPASSWD: /usr/bin/tail" | sudo tee /etc/sudoers.d/mail-monitor

키보드 단축키

키기능
f사용자/도메인 필터
1~5이벤트 종류 토글 (로그인/수신/송신/반송/거절)
space일시정지 / 재개
c화면 클리어
q종료
