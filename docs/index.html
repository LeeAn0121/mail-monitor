mail.log를 실시간으로 읽어서 로그인·수신·발신·반송·거절을 색으로 구분해 보여준다. 누가, 어느 IP에서, 누구에게 — 발신자 실명 조회와 메일 제목까지. 로테이션된 이전 로그까지 /로 검색. r로 발신량 랭킹 — 탈취된 계정이 스팸을 뿌리기 시작하면 바로 눈에 띈다.

Ubuntu/Debian용 .deb · Releases에서 수동 설치
01

이벤트 다섯 가지

LOGIN

누가 어디서(IP) 로그인했는지. 가장 시끄러운 이벤트라 기본은 숨김 — 필요할 때만 켠다.

RECV

누가 누구에게 메일을 받았는지. 발신자 IP와 이름까지, 별칭/포워딩으로 온 거면 원래 주소까지 붙여서 보여준다.

SENT

이 서버가 밖으로 내보낸 메일. 어느 릴레이를 거쳤는지 같이 표시.

BOUNCE

반송된 메일 — 왜 실패했는지 그대로 남긴다.

REJECT

거절당한 메일. 스팸/불법 릴레이 시도를 가장 먼저 잡아낸다.

02

키보드

f필터 — 메모리 버퍼(최근 5000건) 대상
/이력 검색 — 디스크의 mail.log + 로테이션 로그 대상
r발신량 랭킹 — SENT를 발신자별로 집계
1–5이벤트 종류 토글
space일시정지 / 재개
c화면 클리어
q종료
03

옵션

--subject 메일 제목 표시

기본 로그엔 제목이 안 남는다. Postfix header_checks로 Subject만 평문 노출하도록 설정하면 자동으로 잡아서 보여준다. 로그에 제목이 평문으로 남으니 접근 권한을 고려할 것.

설정 방법 (README)

--names 실명 조회 (MySQL)

users 테이블(email, name)에서 실명을 조회해 이름 <email> 형태로 보여준다. DB 정보는 코드에 넣지 않고 환경변수 MAIL_MONITOR_DB_DSN 또는 .env 파일로 전달.
