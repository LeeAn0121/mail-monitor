📧 mail-monitor

Postfix / Dovecot 로그를 실시간으로 보여주는 터미널(TUI) 대시보드. Go + Bubble Tea

설치 / 업데이트

curl -fsSL https://leean0121.github.io/mail-monitor/install.sh | bash

이미 설치된 상태에서 다시 실행하면 최신 버전으로 덮어 설치됩니다. Ubuntu/Debian용 .deb 패키지를 GitHub Releases에서 받아 수동으로 dpkg -i도 가능합니다. 설치된 버전 확인: mail-monitor --version

실행

mail-monitor

/var/log/mail.log 읽기 권한이 필요합니다. sudo 비밀번호 없이 실행하려면:

echo "$USER ALL=(ALL) NOPASSWD: /usr/bin/tail" | sudo tee /etc/sudoers.d/mail-monitor

실행하면 최근 100줄을 이력으로 보여준 뒤 실시간으로 이어집니다. LOGIN은 가장 시끄러워 기본적으로 목록에서 숨겨져 있습니다 (카운트는 집계됨, 1로 토글).

메일 제목(Subject) 표시 (선택, 서버 설정 필요)

기본 로그엔 제목이 안 남습니다. header_checks로 Subject만 평문 노출하도록 설정하면 표시됩니다. ⚠️ 로그에 제목이 평문으로 남으니 접근 권한/보존 정책 고려하고 적용하세요.

/etc/postfix/header_checks:

/^Subject:/ WARN

/etc/postfix/main.cf에 추가:

header_checks = regexp:/etc/postfix/header_checks

반영 (재시작 불필요):

sudo postfix reload
